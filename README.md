# Student Management API

A backend REST API built with **Java 21 and Spring Boot** to practice and demonstrate core backend development concepts, including REST APIs, layered architecture, dependency injection, validation, exception handling, configuration, logging, DTOs, and unit testing.

## Tech Stack

- Java 21
- Spring Boot 4.1.0
- Maven
- Spring Web
- Spring Validation
- JUnit 5
- Postman
- Git & GitHub
